# Folio · Dashboard de campañas

Dashboard de demostración construido exclusivamente con HTML semántico y Tailwind CSS v4 compilado localmente.

```bash
npm ci
npm run build
```

Abre [index.html](index.html) en el navegador. Opcionalmente, `npm start` sirve el dashboard en `http://localhost:3000` (requiere Python 3). Para recompilar al editar, utiliza `npm run watch`. Ejecuta las pruebas con `npm test`.

Consulta [README.md](README.md) para ver la estructura completa, fórmulas, criterios de atribución, accesibilidad y documentación de los datos demostrativos.
